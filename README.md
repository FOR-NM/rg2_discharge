# Discharge 

Adapted from https://github.com/Watershed-QuEST/discharge.git


In this repo you will find semi-automated discharge calculations for salt slugs for the NM: New Mexico Santa Fe River. 


## 📂 Project Structure

```text
├── data   # where raw and formatted YSI and SCL files should be stored 
├── outputs  #outputs for the 
├── R   #aider functions/ scripts 
│   ├── removeInitialNoise.R
│   └── split_file.R
├── rg2_discharge.Rproj
└── scripts  # Main scripts for caclulating Q and running analysis
    ├── 00_formattingSCLfiles_NM.R
    ├── 00_formattingYSIfiles_NM.R
    └── 01_calculatingQ_NM.R
```
